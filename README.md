## Featured Projects

### Collabrium | Manual Testing · Graduation Project

**Collabrium** is an integrated enterprise management platform that brings project management, task tracking, bug reporting, team collaboration, learning resources, and performance monitoring into one system.

**My role focused on manual testing:** checking application features and user workflows, comparing actual behavior with expected results, and identifying issues that could affect usability or functionality.

Testing a platform with multiple connected modules helped me understand how individual features contribute to the overall user experience and why testing complete workflows matters.

### ParaBank | Cypress Test Automation · In Progress

An end-to-end test automation project for a banking demo application, built with **Cypress and JavaScript**.

**Current coverage**
- Registration with valid data, missing required fields, mismatched passwords, and duplicate usernames.
- Login with valid, invalid, and empty credentials, plus logout verification.
- Creation of CHECKING and SAVINGS accounts, including verification of the resulting account type.
- Fund transfers between different accounts and validation of transfer result details.
- Exploration of empty, zero, negative, and same-account transfer scenarios.

**Implementation**
- Organized tests by application feature.
- Separated test data from test logic using JSON fixtures.
- Created reusable custom commands for login and account creation.
- Used assertions to verify visible messages, page content, and account details.
- Documented potential defects with reproduction steps, screenshots, and transaction-history evidence.
